# ReasoningBank Research Slides

先从论文和时长确定听众要理解什么，再用论文原图与讲者备注组织可讲的报告。页面直接沿用 Arthur 确认的 ReasoningBank 原模板。

## 默认主流程：paper → 听众理解的论证

1. **开场收论文和时长。** 简短邀请用户提供论文 PDF 或链接以及报告时长，例如「20 分钟演讲＋5 分钟 Q&A」。已有哪项就只补缺项。拿到论文即可读正文与关键附录。
2. **确定讲述结构。** 按 [内容取舍](references/paper-to-talk.md) 和 [时长规划](references/duration-planning.md) 确定一个贯穿问题。简短告诉用户本次的理解目标、展开深度、时间分配和备份取舍，然后开始正文。短时报告合并背景、压缩机制、精选证据。
3. **封面前确认署名和学校。** 在结构确定后合并询问尚未确定的项。有适用的历史配置时，列出标明来源的「沿用」选项，允许直接修改其中一项。等待回复时继续制作正文与讲者备注。按 [署名和学校规则](references/personalization.md) 定稿封面及页头。

按下面六环组织默认报告。环节可拆多页或按材料合并，逻辑关系保持清楚：

1. **问题为什么值得听。** 用具体任务、失败或矛盾建立需要，明确这篇paper最值得讲的内容。
2. **必要背景与已有做法。** 只补后文机制/图表的前置概念，减去听众已经知道的内容；让已有方法的瓶颈可见。
3. **作者抓住了什么关键idea。** 用一句话和同一例子的旧/新对照，指出改变了哪个对象、操作或学习信号。
4. **机制怎样运行。** 总览先定位，随后用一个贯穿案例依次解释输入、操作、输出与状态变化；每页/每次揭示只增加一个推理依赖。
5. **实验究竟支持什么。** 先确定实验问题、比较对象和指标，再选图。主收益、消融、代价、泛化或失效分别回答具体问题，不读完整表格的每个格子。
6. **知道什么，还不知道什么。** 回答开场问题，保留关键限制，从证据缺口提出讨论；是否扩展到general topic依目标、来源与时间判断。

**背景讲多少、机制如何展开、实验选什么图**，在流程参考中有具体决策方法。标题说主旨，图表展示关系或证据，口头解释读图路径和推理。结论可用一句大字；机制和证据页优先让听众看见“为什么”。

讲述结构无需另行审批。按需合并记录证据与取舍、逐页设计、原图来源、讲者备注、讨论与检查结果。

**扩展由 agent 判断，不默认扩成领域综述。** 窄问题报告围绕论文完成论证；需要少量领域背景时只补支撑主线的概念；面向 general topic 的报告才把论文作为案例组织更广地图。记录选择与理由，并按用户已有要求直接推进，具体门槛见流程参考。

## 核心 philosophy

1. **问题牵引叙事。** 每页解决一个理解障碍，结尾为下一页创造需要。先理解材料和信息关系，再决定布局。
2. **总览定位，机制在前，案例接上。** 先用论文原图定位，再根据时长口头串起输入、操作、输出和保留状态。需要拆解时沿用同图或放大其原始分面。
3. **表达形式由关系决定。** 选能直接支持该页主旨的原图、原表或大字结论。具体选择见 [表达方法](references/philosophy.md)。
4. **标题承担信息。** 结果页用有证据的短结论；机制页用短行为陈述或明确问句；定义页直接命名对象。正文推进标题，避免重复。
5. **低密度服务于理解。** 大字、浅底、留白和大图；内容多就拆页。原表、原 prompt 等证据可单独成页，保留影响结论的条件与标签。
6. **证据与讨论相接。** 把测到的结果、解释、限制和研究假设分清。关键限定留在结论旁，完整引用、实现差异和讲述过渡放备注。

## 制作约定

在工作稿中为每页记录：`听众问题 / 唯一主旨 / 保留证据及来源 / 视觉形式及理由 / 展开顺序 / 讲者备注与过渡`。这份设计记录属于制作产物，不放进正式页面，也不另设前置审批。

按报告实际长度编排。通常从具体问题与必要概念，进入系统总览和机制，再看评测、结果与边界，最后提出研究问题。每个区段是否需要、需要几页，由材料决定。43 页、ReasoningBank 的模块、UNC 标识、作者、日期和旧数据不是新报告的必填项。

先完成有实质内容的代表性中间页，再扩展全稿。**内容图只用所讲论文的原图、原表或保真裁切。** 保留轴、图例、单位、比较组和影响解读的原始标签。缺少合适的原图时，用大字结论配讲者备注。按 [原图选用](references/image-playbook.md) 和 [机制图展开](references/diagram.md) 实施。

讨论题从本页证据或机制的具体分歧产生。读 [讨论设计](references/discussion.md)，为所选问题保留预期讨论方向与追问，不在每页强塞问题，不把一般讨论写成知识问答。

需要说明步骤时优先拆页，让同一个图的对象与位置保持稳定。使用点击揭示时，每次只增加一个推理依赖；静态导出应有完整可理解的最终状态。

幻灯片标题、结论和必要的短标签保持为可编辑文字，论文图表作为原始素材嵌入。页面用大字保留主旨和改变解读的条件。详细解释、参数、读图步骤和来源定位写在对应页的讲者备注。

## 如何使用逐页分析

[43 页逐页分析](references/page-by-page.md) 记录历史成稿的表达与取舍。从同类页选择布局，优先复用其阅读顺序、图位与留白。历史插图与生成提示用于理解原稿。

## 视觉参照与制作

- 读取 `artifact-template.json`，以 `assets/reference.pptx` 为模板源。按 [原页索引](references/reference-map.md) 和 [视觉规格](references/visual-system.md) 选定原稿的封面、机制、证据和收束页。
- 用 [Presentations](plugin://presentations@openai-primary-runtime) 在原模板副本中复用对应页面或布局。保留画幅、蓝带、校标位、标题位置、字体、留白和图框几何，替换内容。遇到整页位图或输出为其他格式时，按对应原页的实际几何复建版式层。

## 完成判断

- 每页主旨和改变解读的条件在投影尺寸下可读，详细解释与来源可在对应页备注中找到。
- 已说明时长对应的结构与总结深度；演讲、互动和Q&A合计符合约定时段，预计时长不冒充已排练的实际时长。
- 在实际展示尺寸逐页检查文字、原图边界、裁切和层级；核对原图版本、图号、轴、单位、比较对象和备注定位。
- 与保留稿中对应家族的中间页比对字体、间距、比例和信息密度；检查可编辑性、备注与引用。含视频或揭示则验证相应功能。
- 署名、机构及模板遵循本次配置；检查封面、原生页、继承图片、备注和文档元数据没有残留的旧机构或旧讲者。原论文作者与原始证据中的机构属于来源，不因换报告机构而误改。
- 渲染、导出和检查遵循当前用户的计算环境与授权；缺少条件时说明未验证的部分，不把既有原稿的 QA 当作新稿通过。

用户的新内容和明确偏离优先；没有另行指定时，沿用这份最终稿的格式与表达方法。
