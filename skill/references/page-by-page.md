# ReasoningBank最终稿：43页逐页分析与可迁移做法

本分析基于2026-11-13最终43页稿：40页正片，41页备份分隔，42–43页按需备用。逐一查看已有的43张选定版本PNG，并核对最终PPTX的原生文字和讲者备注；没有在此次分析中重新渲染或测试视频。

每页分别说明作用、看得见的优点、具体改进、可复用做法、图像类别及可问的问题。改进是建议，不代表原PPTX已被改动。用户喜欢的白底、蓝色重点、大字与留白保持不变。

## 整体判断

最值得迁移的是“具体任务建立概念→总览定位→同一案例展开机制→评测先定义比较坐标→证据旁保留边界→从缺口进入研究问题”。需要改进的主要是原表/原图过密、少数比较轴不一致、部分箭头含义过强及抽象结尾缺少可判断的具体变化。

下面是历史页例。新稿复用其版式和讲解顺序，素材按 [原图选用](image-playbook.md) 从当篇论文取得。页例中的生成手法及重绘建议保留为历史记录。完整制作流程见 `paper-to-talk.md`，讨论设计见 `discussion.md`。

## 本段最值得写入技能的三项规则

1. **以一个可操作案例贯穿对象展开。** 购买案例先用于解释缺失证据，再依次承担trace、Judge、atom、writeback、pool和retrieval；原图总览与局部定位让听众一直知道正在解释哪一步。换例时明确提示。
2. **主旨提炼必须同时产出证据边界。** 将论文原始案例、教学改写、示意预算、实测曲线、实现细节与未披露项分开记录。大字结论不能把案例升级为因果，把记录上限升级为实测规模，把代理Judge升级为真值。
3. **按关系选图，并把准确文字留给原生对象。** 系统关系用流程/泳道，信息层次用字段表，数据规律用图表；生成图用于直觉和任务场景。提示词写清对象、关系、强调点与白底蓝色风格；日期、数值、技术标签、比较结果用原生文本叠加，来源和讲解路径进入备注。

# 从这些页抽出的制作规则

## 扩展到更大主题的关口

1. **先完成单篇证据账。** 31–35先回答执行步数、完整开销、额外尝试、随机一次、候选覆盖与答案选择。未分清评价协议之前，不跳到“记忆使智能自进化”等大命题。
2. **扩展必须有具体桥。** 35的选择缺口、37的适用前提、39的规则失效，是能够带出新方向的问题；36的领域地图应为这些问题提供坐标。若一个相关方法既不解释差异，也不支持后文问题，就不因热门而加入。
3. **方向图要区分三层。** 已测结果、合理解释、待验证假设各用清楚语气。38的中心表征是作者假设，不能从若干前例推为统一已证实架构；42的项目地图也不表示每个项目已经完成。
4. **主题越大，例子越具体。** 由首次订单的覆盖要求进入skill触发，再由局部规则的真实变更进入持续学习。若只能画抽象框图而说不清一次行为分歧，先补案例。

## 讨论问题的设计

- 每个问题写清讨论对象与希望区分的解释。34的等预算、打乱/无关记忆控制比泛问“记忆是否有效”更有产出。
- 从一个已知缺口提出一个可执行判断：35问如何缩小选择缺口；37问何时拒绝套用经验；39问什么后续证据使旧规则失效。
- 答案不应藏在问题的措辞里。允许“额外尝试本身有价值”“语义相似仍可有用”“表征未必是首要瓶颈”等可能性，再说明什么证据能决定。
- 报告结束优先保留一个讨论入口；其他问题作为按需跳转备份的索引，避免问句密集而无人有时间回答。

## 历史页例中的图像类别

- **原始定量证据（31–35）：** 优先源图或准确可编辑重绘；不让生成模型画数值、曲线或表格。提示设计仅涉及裁切与旁注位置。
- **操作教学示意（37）：** 提示应指定具体对象、触发条件、操作、验证和失败出口；固定对象位置。可生成无文字的组件外观，标题、文字、箭头由可编辑层承载。
- **有来源的研究地图（36）：** 先人工确定分类、日期口径与关系；图标只辅助识别。禁止让生成模型自由补论文、继承关系或年份。
- **作者概念图（38）：** 提示先写“这是待验证的关系假设”，列出每条关系的口头解释，控制节点数量；不让美观的箭头替代逻辑。
- **时间与证据隐喻（39–40）：** 浅色、低饱和、白底、少量文档/时钟/放大镜，留出大字区域。只承担记忆线索；真正的规则、变化及影响用明确文字或状态图表达。
- **原始复杂方法图（43）：** 保留证据完整性，用连续页放大编辑、评价、学习三个局部；不重新生成貌似相同但细节改变的“原图”。

新稿选择原图和分面时，先确定靠这张图讲清什么，再按当前论文核对图号及内容。
