# 从 paper 到可讲的完整报告

默认主工作是选择内容、建立理解依赖并组织证据，让听众能解释方法、判断结果、参加讨论。先读论文并推进下面六步：

`具体问题 → 必要背景与基线 → 关键想法 → 机制逐步展开 → 证据 → 结论与限制`

某一步可用一句话，也可拆成多页。根据材料和听众已有知识决定页序。开场只补缺少的论文或时长，已有论文就开始读。

按 [时长规划](duration-planning.md) 明确演讲与 Q&A 或互动预算，选择贡献速览、概览、标准报告或深入研讨。简述理解目标、带时间的结构和内容取舍。然后按 [署名和学校规则](personalization.md) 合并补问尚未确认的封面信息，正文和备注继续推进。

## 阅读与内容分流

从用户给出的原论文入手，核对版本；读摘要、引言、方法、主图、评测设置、关键结果、消融、限制与支撑主张的附录。源材料有缺页或尚未读到时记录范围；只把确实读到的内容写成已核验。实现细节另保留代码版本；论文与当前实现有差异时并列说明，避免用今天代码反推发表实验。

建立简洁证据表：`问题 / 最相关既有做法 / 改变行为的新机制 / 支持的主张 / 图表或章节定位 / 比较条件与代价 / 尚未回答的问题`。来源事实、作者解释、讲者推断、教学示意和研究建议分别标记。

将候选内容按它在报告中的作用分流，再决定页数与版式：

| 去向 | 纳入条件 | 常见内容与处理 |
|---|---|---|
| **main：主线** | 直接回答贯穿问题，或支撑/限制核心结论 | 具体失败、核心机制、关键比较、会改变结论的限定；正常讲述 |
| **bridge：桥接** | 听众理解下一项主线内容需要，但本身不是贡献 | 必要术语、最小基线、指标读法、步骤间的状态交接；用一句话、一个例子或短页补足 |
| **backup：备份** | 有依据且对追问有用，跳过仍能理解并判断主结论 | 完整结果表、次要变体、推导细节、实现参数、额外案例；在备注或备份保留定位 |
| **omit：舍弃** | 不服务当前问题，或重复已有信息且没有新增证据 | 与后文无关的背景、方法名清单、重复结果、只为模仿原稿而加入的模块 |

影响结论的条件、反证或失败不能因不方便讲而移入备份。没有来源的数字和比较不进入正式结论；记录缺口，不为图文齐全补造数据。内容分流可随阅读更新，不把第一版 outline 当成已完成理解。

## 1. 具体问题：让听众知道为什么需要这项工作

用一个任务、失败或矛盾呈现问题。说明谁要完成什么、输入和期望输出是什么、既有做法在哪个条件下受阻。若是理论论文，用待解释的现象、反例或尚未满足的性质建立问题。

先在内部提出少量讲法，再根据材料选一个贯穿问题。它必须穿过方法与主要证据，结尾能回答其适用范围。写成四句话：

> 听众起初可能认为【直觉/既有做法】。这篇论文用【关键改变】处理【具体障碍】。我们重点看【关键比较】能否支持【核心主张】。结束时，听众应能判断【适用范围/未解问题】。

“介绍最新 Agent Memory 工作”太宽；ReasoningBank 的可用问题是“怎样把一次执行变成下次能用的经验”。主题不能预设实验已证明机制解释；证据不足时收窄主张。

### 自主决定是否扩展到 general topic

用户已经指定范围时遵循指定。否则按可观察条件选择并继续制作，不为常规范围取舍增加审批：

| 模式 | 选择条件 | 结构与边界 |
|---|---|---|
| **论文中心，不扩展** | journal club、复现、审稿式解读或短时报告；现有材料足以回答主问题 | 六步主线围绕论文；讨论仍从其证据出发 |
| **论文中心，有限扩展** | 理解贡献需要少量外部概念，或明确限制引出一个领域问题；有来源与时间 | 背景或结尾短桥接；每项扩展能指出它解释了论文哪一处 |
| **general topic，论文作案例** | 用户目标是领域介绍/研究方向；需要比较多类系统，且有足够来源 | 按共同问题和维度组织领域，以论文作深入案例；明示超出论文的部分 |

依次判断：不补会误解论文吗？机制或实验留下了哪个具体可迁移缺口？外部比较有一手来源吗？加入后会挤掉方法理解或关键证据吗？工作记录写 `模式 / 为什么 / 加什么 / 省什么 / 对应证据 / 时间影响`，无需打分或固定配额。没有用户指定范围且扩展依据不足时选择论文中心。

用户明确要更广主题但来源不足时，先补读可访问的一手材料，完成有依据的框架、案例与评估维度。仍缺依据的跨方法排名、历史关系和实证结论保持空缺并说明；必要时请求所需材料，不把框架称为完成的综述，也不悄悄改成单篇 journal club。

ReasoningBank 最终稿扩展到 Agent Memory 有明确研究目标，也能从检索数量、标签可靠性、记忆过时等问题桥接。它不意味着下一篇论文也需要 Agent Memory 地图。

## 2. 必要背景与基线：只补后文真实依赖

背景量由 **理解后文所需的前置知识，减去听众已经掌握的部分** 决定，不按报告总时长分配固定比例，也不按领域百科列章节。从报告对象与用户信息推定听众基础；信息不足时记录工作假设并先推进，避免默认从零介绍整个领域。

为每项候选背景记录：`后文哪张图/哪句主张依赖它 / 必须理解的内容 / 听众已知什么 / 用什么最短形式补足`。找不到后文依赖的内容移到备份或舍弃。以下读法决定保留多少：

- 听众已理解概念：在首次使用处直接调用或用一句话唤起。
- 缺一个术语或对象边界：用具体任务配一句定义。
- 看不懂方法为何改动：先展示最相关基线如何处理同一输入，标出其失败或限制。
- 看不懂结果：在结果前补任务协议、指标方向和必要比较条件。

基线讲到听众能回答「新方法究竟改了哪一步」即可。对齐输入、输出、目标与预算，保留后文实际比较的差别。贡献依赖领域分类时，采用论文已有的分类图，或用大字点明比较维度并口头展开。

背景完成的判断：听众能理解关键想法和后文证据的读法，而不是已经听完全部相关工作。约一小时报告也不能用背景挤掉机制展开与关键证据。

## 3. 关键想法：把贡献压成一个可解释的改变

用一句话说明“相对基线，改变了什么对象、操作、学习信号或假设，因此期望解决哪一处障碍”。让听众先看到这个改变，再接触全部模块名。

找能显示差异的最小表达，例如论文中的并列路径、前后状态或反例。缺少合适的原图时，用一句大字指出差异，在备注里写口头例子。

## 4. 机制：先全图，再让同一个例子逐步走完

先给论文原总览，口头说明起点、终点、主要对象与依赖方向。随后按因果依赖分步讲解。可保持原图位置，或等比放大适合单独阅读的原始分面。缺少总览时，用大字点明这一页的操作及输出。

选一个能走过核心路径的稳定案例，先交代初始输入与状态。每一步填写：

`进入什么输入/状态 → 执行什么操作及依赖什么条件 → 输出什么对象 → 更新/保留什么状态 → 下一步如何使用`

一页或一次揭示只增加一个理解所需的依赖：先有对象，再有作用于它的操作，再看到变化如何供下一步使用。若一次要解释多个互相独立的变化就拆页；保持未变部分稳定，让听众能指出“刚才到底变了什么”。静态导出须有可理解的完整终态。

案例随步骤演化，而不是每页换一个场景。机制定义与案例实例分开：先讲通用操作，再显示本例的具体输入/输出。必须换例时标明切换；真实轨迹与教学示意注明身份。一个成功案例不能替代总体实验，也不能把示意中的对象说成论文实际输出。

理论论文从总命题与假设出发，用论文原图、大字命题或口头例子逐步讲清推导和反例，说明每步依赖哪些假设。

参考原稿：9–15 页用于总览与机制定位；19–22 页用于任务定义。具体布局按当前对象关系选择，不能保留 ReasoningBank 模块充数。

## 5. 证据：先问实验回答什么，再选图

围绕贯穿问题选择核心证据，不按论文图表编号逐张转述。每张结果页先写：`要回答的问题 → 需要比较什么/固定什么 → 用什么指标 → 哪种图能直接显示答案 → 结论及范围`。详细选择见 [实验问题与图表](experiment-figures.md)。

依材料选择主收益、消融、代价、泛化、稳健性证据；这些是检查主张的角度，不是必须各造一页的目录。主收益说明做得是否更好；消融检查哪个改变与收益相关；代价决定收益在何种预算下成立；泛化和稳健性检验范围。论文没有测到的角度写成缺口，不用生成插图填满。

使用可读的论文原图、原表或保真子图，在备注中说明读法与来源。只有文字、公式或数值时，选一条有依据的结论用大字呈现，推导、反例和条件可口头说明。

原表太密时放大支撑当前问题的原始区域，保留相关行列标题、单位和会改变结论的条件。结果页用短结论与大幅原图，必要限定以大字呈现，读图步骤和细节写进备注。参考原稿 24–35 页的图位与阅读顺序。

## 6. 结论与限制：回答开场问题，再打开研究问题

结尾只保留证据支持的几个答案，明确它们在什么任务、模型、预算或假设下成立。将最影响判断的限制与相应结论放在一起；不把全部限定藏到最后一页或备注。

需要讨论时，从已讲过的机制或证据出发：`观察到的结果 → 未区分的解释/未覆盖条件 → 可检验问题 → 能区分它们的对照`。读 [讨论设计](discussion.md)，选少量值得停顿的问题，区分中途理解检查与结尾研究讨论。不默认扩成领域综述；只有用户提供个人研究方向时才写“My research”。参考原稿 36–40 页的桥接与收束，41–43 页的备份定位。

## 从主线到逐页制作

依据讲述与互动估计时长，不用固定页数乘每页一分钟。若超时，先删重复与非依赖背景、将次要证据移备份，再检查主线是否仍能独立成立；不靠缩字或省略关键限制赶时长。

每个区段和关键页记录预计讲述/读图/转场时间，按 [时长规划](duration-planning.md) 检查总预算。用户改变时长时，一并重做主线、桥接、备份、机制细节、证据和讨论安排；保留短版完整结尾。没有排练时，交付称为“预计”，不称已验证能在指定分钟内讲完。

每页在工作稿中写下：

```text
听众问题：这页消除哪个理解障碍？
唯一主旨：一句能被这页支持的话
去向与依赖：main / bridge / backup；承接什么、供下一页使用什么
证据：精确来源、比较条件、结论边界；是否为教学示意
视觉：表达哪种关系、为什么选择这种图；对应哪张参照页
原图：论文版本、图表编号、使用分面和保留条件
展开：初始状态与每次增加的一个推理依赖
讲述：核心一句、解释、过渡、可选讨论题；预计时间
```

该记录保留在工作稿。先完成有方法和具体例子的代表性中间页，再检查并扩展全稿。用确认后的署名和学校定稿封面。

按 [原图选用](image-playbook.md) 核对素材版本和裁切，按 [机制图展开](diagram.md) 写分步讲稿。制作时直接复用 [视觉规格](visual-system.md) 对应的模板页。新增标题与结论保持可编辑。

## 检查与交付

**内容：** 六步之间有理解依赖；每项背景指向后文；标题与证据匹配；比较条件可读；案例与术语跨页一致；外部来源可追溯；未测结果与研究假设没有写成事实。

**视觉：** 在实际展示尺寸逐页检查；与对应参考家族比对；读图顺序明确；内容多已拆页；图像语义准确；中英字体无缺字；来源细节在备注，影响结论的条件在页面上。

**功能：** 检查可编辑对象、媒体、揭示顺序及静态终态。渲染、导出与检查遵循当前用户授权的环境；不能把源稿已有 QA 算作新稿通过，未验证项如实说明。

交付用户要求的演示文件或页面，保留必要备份与讲者备注。简要说明贯穿问题、范围决定及影响使用的未验证项。没有请求时不倾倒内部制作记录；用户要求分析时提供相应文件。
