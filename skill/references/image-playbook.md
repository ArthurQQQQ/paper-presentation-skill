# 选用论文原图

先确定这页要让听众看见什么，再从所讲论文正文、附录和同版补充材料选原图、原表或案例截图。校标、标题蓝带和分隔线沿用原模板。内容图使用论文实际发表的素材。

## 获取与放置

1. 核对论文版本和图表编号。优先取作者发布的原图文件，或从同版本 PDF 提取。只有 PDF 排版时，可用高分辨率渲染保留原图或原表区域。
2. 按原模板的图框等比放置。复杂原图优先用整图定位，下一页再放大原始分面。裁切保留相关轴、图例、单位、比较组和影响读法的原始标签，并在备注指明取用范围。
3. 保持原图内容完整，不生成插图、不重绘机制图或实证图表、不改动图内文字和数值。缺少合适原图时，用原模板的大字页提出主旨，口头讲解或取舍该内容。
4. 在对应页备注写明论文版本、图表编号及页码或链接、讲者读图顺序、比较条件与限制。页面保留必要的大字结论和影响读图的条件。原图已有的轴与图例留在原处。

## 检查

逐页与论文核对图像来源、原始标记、比例和裁切；用实际展示尺寸检查主图的关键信息是否可读。原表太密时另用聚焦页放大其原始局部，或放入备份。

原模板中保留了历史插图与 [实际检索图 prompt](diagram-original-prompt.md)。它们用于查阅原稿的制作记录。新稿从本页流程选取素材。
