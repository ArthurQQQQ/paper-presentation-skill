# 字号与排版：生成后的视觉修订轮

第一版生成后，先从听众视角读完、看完，再交付。已有“渲染成功”“无溢出”或 contact sheet 不代表字号和排版好看。这个修订轮检查视觉层级和阅读节奏，发现问题要落实修改，并查看修改后的实际渲染。

## 先建立文字角色

沿用所选模板页族的字体与尺寸作为起点。下面描述本模板的常用层级，不作为脱离内容的强制字号：

| 角色 | 起点与检查重点 |
|---|---|
| 封面标题 | 原模板约46pt；按语义换行，检查蓝带内的行距、上下留白和重心 |
| 正文页标题 | 原模板约29pt粗体；同类页稳定，短句优先，必要时调整行框而非挤成超长一行 |
| 正文 | 通常22pt常规字重；与标签区分，不从某个模板对象继承整段粗体 |
| 必要副标题/比较条件 | 约18–20pt常规；从属于主标题，删去重复标题的装饰性kicker |
| 标签/结论 | 常用20–24pt，按作用选择字重；大数字可更大，但不要让每块文字都抢主位 |

用户已选字号或明确要求时优先沿用。相同角色跨页尽量一致，大小变化必须对应角色变化。复制文本框后显式检查实际字号、粗体、对齐、内边距和行距，不能只沿用它的对象名称或theme。

## 一轮怎么做

1. **先看全稿节奏。** 用整稿缩略图发现某页标题/正文突然变大、某张表格过大而相邻图又太小、正文全粗体、页间重心或留白跳动。
2. **逐页看实际画面。** 每页在一致的fit-to-slide尺寸查看，再单页检查。先找主标题和唯一重点，再读副标题、正文、图内关键标签、结论。检查自然换行、孤立短行、裁切、行距、对齐、图文比例，以及图下的留白；不要靠放大到数倍才能读清来判通过。
3. **按文字角色修。** 正文抢重点时先去掉多余粗体；副标题抢主标题时压低层级或删除冗余；长标题先提炼或按语义断行，再调文本框；解释多时移入备注或拆页。不要整套统一放大、自动缩字塞满，或为美观删去会改变结论的条件。
4. **检查原图的有效字号。** 图片里没有可编辑的字号，也须判断投影后是否可读。原表比标题还抢眼、原图轴和图例过小时，调整放置尺度，或“完整原图定位页＋原始局部放大页”。裁切必须保留相关轴、图例、单位、比较组和限定；必要时完整图入备份。不得修改原图文字、数值或拓扑。
5. **重新渲染并复看。** 查看每个改过的页面；若改了共同字体、页族或母版，复看所有受影响页。最后再看一次整稿缩略图，确认字号、字重和留白连贯。新增正文页时重新核对演讲时长，备份与正文明确区分。

不要只给检查清单而不修改已发现的问题，也不要在修改前的旧图上宣布通过。保留清楚的最终版，过渡图不作为最终验收依据。

## 内部记录与完成门槛

每个问题简记：`页码/文字角色 → 实际可见问题 → 已做调整 → 修改后图`。无需给用户倾倒审查表；交付可简短指出最主要的修正。

交付前应能回答：看过了哪些最终页？标题、正文、条件和图内关键标签分别是否可读？哪些字号/字重/换行/图文比例实际改过？修改后的渲染是否再次查看？只有完成最后一项，才可称已完成视觉修订。

渲染遵循当前计算环境与已有授权。缺少渲染条件时继续做内容、源文件和已有图的检查，明确最终视觉轮尚未完成；不能把读取字号值、历史参考稿QA或“导出未报错”当作本次最终验版。
