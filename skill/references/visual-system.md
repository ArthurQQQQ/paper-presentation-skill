# 最终稿的视觉规格

以 `assets/reference.pptx` 为制作模板，以已渲染的中间页 PNG 核对输出。这是 2026-11-13 的 43 页版本。新稿在副本中复用与内容对应的原页面或布局。下面给出的原生 PowerPoint 单位是英寸与 pt。

## 固定视觉基础

| 项 | 最终稿数值/做法 |
|---|---|
| 画幅 | 16:9；13⅓ × 7.5 in |
| 页面 | 白底 `#FFFFFF` |
| 标题/强调蓝 | `#345E9F` |
| 深蓝文字 | `#173C65` |
| 正文墨色 | `#20262E`，继承证据页可接近黑色 |
| 浅色机制面板 | `#F3F8FC`，边线 `#D3DDE8` |
| 主强调/封面蓝 | `#1C4FA0`；继承导航激活色约 `#1C4CA0` |
| 原生字体 | Arial；图/继承页保留来源字形，不整体强行换字 |
| 机制页标题 | 29 pt，bold，蓝色；约 x=.45, y=1.12, h=.47 |
| 主体文字 | 通常 22 pt；强调语句约 23–24 pt |
| 标题下短线 | x=.47, y=1.67, w=3.65；1 pt，`#C6CFDA` |
| 主要左右留边 | 约 .45–.65 in；新稿以对应布局原对象为准 |

先选对应页面家族，再复制其中的具体几何。正式画面放大字观点、必要条件和论文原图。解释细节、实现参数、来源和读图顺序进讲者备注。原图自带的标签、轴与标记保留。

## 页面家族

### 封面

复用第 1 页。上方居中为学校标识，中间横贯蓝带和白色大标题，下方为确认后的署名。蓝带约 y=2.44、h=3.12，标题约 46 pt。按本次确认替换身份信息，日期按实际需要填写。

### 机制页：原图总览与局部解释

- 左上标识约 x=.45、y=.17、w=2.15，保留比例。
- 第 9 页的标题、图框和底部一行讲点可直接用于大幅原总览。
- 需要局部页时沿用第 13–15 页的图位与阅读顺序。小总览位于 x=8.88、y=.27、w≈3.97、h≈1.985，跨页保持位置和尺度。标题可用宽度约 8.13 in。
- 局部解释使用当篇论文的原始分面或真实案例图。以短标题和讲者备注组织步骤。

### 证据页：大图与一条结论

复用第 24、28、30 页的标题、图位和结论区。以大幅论文图、表或原始 prompt 为主体。原图较密时另起局部放大页。页头借用原模板标识位，章节导航按报告实际需要取用。

### 研究地图与收束

沿用第 38、40 页的层级与留白。收束可用一条大字结论和一个问答入口。有合适的论文原图时放入对应图位。

## 固定格式与可变内容

署名、机构、标识与模板按`personalization.md`解析个人配置及本次覆盖，不从参考稿自动继承。学校、其他institution、自定义品牌和无机构模式均支持；改变机构默认不改变本套浅色简约美学。无机构时连图片中烘焙的旧机构元素也须处理，研究来源中的作者机构保留。

保留画幅、版式、字体层级、配色、间距、线条与图框比例。不同内容在原模板中选最合适的页面家族。

用户可在这套简约系统内选择字号与喜欢的主色，自动生成相容的标题、正文、浅底和分隔线颜色；这是明确的个性化偏离。记录实际色值和字号，不把新主题配色写成原稿原色。已选择大字号后，不为容纳内容而自动缩小；通过拆页和编排保持可读性。

按新内容替换：论文/方法名、流程模块、证据、实验数字、作者与机构、日期、章节、页数、例子和研究问题。保留 UNC 标识只适用于用户确实在 UNC 语境制作的报告，不把它用于暗示其他人的归属。

新稿默认省去小字出处、解释性脚注和装饰性角标。旧稿的页码按本次明确要求取用。

## 编辑与保真

原稿的部分页面是整页图片。需要替换其中的内容时，仅按原页几何复建版式层，再嵌入论文原图。新标题、结论和必要文字保持可编辑。导入或导出后按参考页核对位置、比例和讲者备注。
