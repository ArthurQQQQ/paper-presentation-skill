# 先定实验问题，再选图

供 [paper→完整报告](paper-to-talk.md) 第 5 步使用。目标是让听众判断证据能支持什么，而不是凑齐图表类型或复述所有实验。

## 每张图的选择链

先填 `问题 → 比较对象与控制条件 → 指标与方向 → 原图或原表 → 可支持的结论与限制`，再制作页面。若说不清要比较什么，先回到论文评测协议。下面的表用于从论文已有图表中选择证据。

| 实验问题 | 比较与指标 | 适合的图 | 必须保留的边界 |
|---|---|---|---|
| **主收益：方法比谁好、好多少？** | 同任务、数据划分、协议下的方法/最相关基线；成功率、误差等真实目标 | 少量离散方法用点图或柱图；跨多任务可用分面图或精简表 | 基线身份、样本/任务范围、指标方向、绝对值与差值的区别；预算不同要显式呈现 |
| **消融：哪项改变与收益有关？** | 完整方法与移除/替换组件；同一目标指标；尽量固定预算与其余条件 | 成对点图、差值图或小型对照表；有多因素交互证据才用矩阵 | 一次究竟改变了什么；共变因素、重新调参等限制；移除后退化不自动证明作者全部机制解释 |
| **代价：收益花了什么资源？** | 性能与时间、token、内存、调用数或费用；相同资源口径 | 有多档真实预算用性能—成本曲线/散点；仅一个设置用并列数值或表 | 成本单位、硬件/模型、单次或总量；步数不等于总 token 成本；推理与训练成本分清 |
| **泛化：换条件后还成立吗？** | 已见条件与新任务/域/模型等，明确何处改变；相同目标指标 | 按变化条件分组点图、分面图或表；确有前后配对才连接 | 是分布迁移、换模型还是同分布新样本；哪些训练/检索信息可用；不能据单域外推全部领域 |
| **稳健性：扰动或假设失效会怎样？** | 噪声、标签错误、输入扰动、容量等受控变化；性能/失败率 | 有序强度用曲线；独立扰动类型用分组点图/表 | 扰动定义、范围、重复测量来源；超参敏感性、随机种子变化与分布迁移不能混称同一种稳健性 |

这些问题按实际主张取舍，不要求五类全有。若论文声称高效却没有可比成本，缺口应靠近高效主张；若泛化不是其主张且未评测，不人为制造一个泛化结果页。

## 用图形表达真实关系

- **曲线**用于确有次序的变量或预算变化；离散方法名不连成趋势线。不要在稀疏观测点间暗示未经验证的连续规律。
- **点图/柱图**用于有限组别的比较；展示差值时交代参照组和单位。百分比与百分点分清，柱图基线不得放大差异。
- **散点图**用于两个连续量或性能与成本的关系；Pareto 前沿只能来自已测设置，不补点制造完整前沿。
- **表格/覆盖表**用于精确值、协议差异或证据是否覆盖某项主张。优先留下当前问题需要的维度，避免缩小整表。
- **案例/失败轨迹**用于展示行为与边界；注明选择方式和身份，不能替代总体成功率或代表性分析。

一张图回答一个主要问题。复杂原图可拆为“先读坐标与比较对象 → 再突出关键差别 → 最后讨论范围”数页；位置和颜色稳定，每次只增加一个读取依赖。图表上的短结论不得比数据能支持的范围更大。

## 按证据形态处理

| 手里有什么 | 页面用什么 | 如何说明 |
|---|---|---|
| 论文原表、原图或同版补充材料 | 使用原图、原表或保真局部 | 核对数据划分、聚合方式、单位、方法身份和版本，备注写清来源 |
| 只有论文原图，取不到精确数据 | 使用可读原图/子图，按可见信息解释 | 不凭目测补出精确数字。需要数字化提取时明确标为估读并保留误差边界；不能冒充作者原始数值 |
| 只有文字结论、数值或个别案例 | 大字写当前证据支持的一句结论 | 备注列出来源和适用范围，案例的代表性随原文说明 |
| 理论、概念或没有实验的论文 | 一条大字命题，辅以合适的论文原图 | 口头讲解假设、推导或反例，备注区分定理保证、解释性示例与待检验预测 |

新跑实验、补成本测量或重新评估是新增工作；遵循当前用户授权与计算环境，不因需要一张好看的图自行启动。没有来源时保留缺口，绝不捏造数字、误差线、显著性、样本数或重复次数。只报告来源实际提供的不确定性；不能把单一固定 seed 结果画成多 seed 统计。

## 做图前的证据卡

```text
实验问题：这项比较试图排除哪种不确定性？
结论：这张图最多支持哪一句话？
比较：方法/基线/条件；改变什么，固定什么
指标：定义、方向、单位、聚合方式、预算口径
数据：paper 版本与图表/附录/数据文件定位；原值/换算/估读
不确定性：来源提供了什么；没有提供什么
图形：为什么这种图能直接回答问题；保留哪些标签和条件
限制：替代解释、未测条件、不能推出的结论
去向：main / bridge / backup；关联的主张与机制页
```

卡片放工作稿或备注。正式页面保留大字结论、大幅论文原图和影响解读的限定。完整引用、协议细节、读图提示和备选解释进入讲者备注。检查原图与实际展示尺寸的可读性。
