# 姓名、机构与首次配置

报告开场先收论文与时长。确定讲述结构后，在做封面前集中确认署名和学校。正文、原图选择与讲者备注在等待回复时继续。用户主动说「设置这个 skill」时可直接进入配置。

## 配置来源与保存

个人默认存到 `${CODEX_HOME}/skill-data/reasoningbank-research-slides/profile.json`；`CODEX_HOME`未设置时用 `~/.codex/skill-data/reasoningbank-research-slides/profile.json`。这是一份agent维护的本地个人配置，不是平台账户资料。只在用户实际提供设置后创建，缺失文件不等于已有默认。

通用skill、源PPTX和示例图保持可分发。姓名、私人logo和上传的机构模板放在上述个人目录及其`branding/`子目录，分享skill时不打包个人配置。任务产物中记录实际采用的有效配置，方便以后查看是哪一份报告使用了哪项覆盖。

使用本次已明确的信息，其次使用适用的个人默认。模板内的姓名和学校仅在用户明确要求沿用对应署名或校标时使用。论文作者与机构保留在来源信息中。

## 封面前的询问

有缺失项时，用一次询问收集。有可核对的上次配置或适用的个人默认时，把实际姓名、学校与留空项写在「沿用」选项里。若用户指定的原模板有另一套可供选择的署名或学校，另列「沿用原模板」并标明来源。没有可沿用的信息时直接询问。支持选项的界面使用可点选选项，并允许输入补充或只改一项。

> 这次封面用哪组署名和学校？可以沿用上次的设置，也可以直接输入要改的姓名或学校。

只问尚未确定的项。接受其他机构、自定义品牌或省略。选项中的历史值在用户选择后用于本次。学校已确认且与原模板一致时用原模板校标，缺少对应校标时用学校名称。到封面定稿仍未收到回复时，省略未确认的署名或学校并在交付时说明。仅在用户明确要求设为默认时保存个人配置。

当前仅请求展示或说明流程时，展示示例即可；不要把示例值自动保存成真实个人配置。

## 四种机构模式

| mode | 收集什么 | 如何制作 |
|---|---|---|
| `school` | 学校显示名称；logo和官方模板可选 | 学校名称/真实标识配合简约版式；用户给官方模板时按实际模板 |
| `institution` | 实验室、公司或其他机构名称；logo/模板可选 | 与学校同等支持，不硬写University或校园元素 |
| `custom` | 自有品牌名称、标识或自定义模板，可留空 | 使用用户品牌素材；缺失素材时使用文字，不虚构标识 |
| `none` | 不需要机构信息 | 不放机构名、logo、旧机构导航或机构专属封面元素，重新平衡留白 |

“填写机构名称”与“使用官方机构模板”分开。未拿到官方模板时，只能称为采用该机构名称/标识的简约版，不能称为官方模板。用户要别的机构模板时使用其提供的真实模板，或寻找可验证的官方来源；尚无模板可先按用户确认的文字品牌制作。

## 最小配置格式

```json
{
  "schema_version": 1,
  "presenter": {
    "display_name": "用户实际提供的名字",
    "show_name": true
  },
  "branding": {
    "mode": "school",
    "display_name": "用户实际提供的学校名称",
    "logo_path": null,
    "template_path": null
  },
  "design": {
    "preset": "reasoningbank-minimal-light",
    "color_policy": "keep-preset"
  }
}
```

这是格式示例，不是已初始化的真实配置。无需为不同人复制一套skill。`show_name=false`时名称可为null；`mode=none`时机构字段与机构资产的有效值为null，即使旧文件仍作为历史素材保留也不加载。相对素材路径以个人配置目录解析。不要保存秘密或读取其他账户资料来补字段。

## 自然语言修改与范围

- “以后/默认/记住/我换学校了/更新我的个人设置”修改持久默认。用户说出新值即可直接更新，不增加重复确认。
- “这次/这份报告/替某人做/把这张封面改成”只覆盖本次，个人默认不变。
- 在专门的skill设置对话里，“把学校改成X”更新个人配置；在制作报告时范围不明，先只用于当前稿并简短说明，用户可再说“以后也用这个”。
- 需要补问的是缺失的实际值、无法区分的机构或必要模板来源，而不是已授权的小文件更新。
- 改机构时同步清空有效的旧logo和旧机构模板，直至用户给出新素材；不把新名称配上旧学校标识。姓名未修改时保留。
- 用户说“忘掉我的配置”时移除该skill自己的默认设置；不据此删除唯一演示稿、原始素材或其他任务文件。

对话例：

> 用户：以后默认署名用林宁，学校写南方大学，不放校标。
>
> Agent：已保存默认署名“林宁”、机构“南方大学”，只用文字标识。
>
> 用户：这次用Independent Researcher。
>
> Agent：本次使用“林宁 / Independent Researcher”，默认机构仍为“南方大学”。
>
> 用户：以后都不放机构。
>
> Agent：已更新默认，之后只显示姓名。

以上是演示对话；没有用户实际回答，不声称完成这些保存。

## 身份与美学分开

更换学校或institution默认保留白底、蓝色重点、大字、留白与内容表达方式；不因校名变化就自动改整套配色。用户明确要求官方配色时使用可验证规范；明确提供别的官方PPTX时，其品牌约束优先，同时尽量保留简洁编排。

`keep-preset`维持这套浅色美学；`institution-brand`遵循已核实的机构颜色；`provided-template`使用用户指定的实际模板。机构名称与版式选择可以独立变化，不能只改字符串就声称已经适配完整机构模板。

## 生成时应用与检查

### 字号与自动配色

用户可选择正文基准字号和一个喜欢的颜色，由agent匹配整套浅色方案。这两项可在首次配置时提供，也可稍后修改；不是每次生成都强制询问的新必填项。优先复用已有选择。

- 字号可以选择参照稿22pt、大字26pt、更大30pt，或用户明确给出的其他值。标题与层级按此同比例调整，保留视觉主次。内容超出时拆页、精简非关键细节或改布局，不因自动适配而把字缩小。
- 输入一个主色，保留白色主背景；自动给出主色、标题色、深色正文、浅底、分隔线及主色区域上的文字颜色。亮色可以作为色块，标题使用同色系的更深版本，正文保持稳定深色。
- 自动搭配要检查实际前景/背景亮度对比。预览使用4.5作为标题对比目标并按主色色块选择白字或深字；这是配色策略，不宣称自动获得完整可访问性认证。
- 预览画面应占据主要宽度，控制项放上方或下方；同时展示有实质内容的方法页和封面，不能只用一个小封面判断整套字号。
- 在报告中明确要求学校官方模板/配色时，遵守已核实的品牌约束；“喜欢这个颜色”的个人方案不自动成为学校官方配色。
- 对话中的交互预览只改变预览状态。用户明确让agent采用后，按“本次/默认”的范围应用；不把示例或随手切换的颜色自动保存为个人默认。

配色选择可在现有`design`对象中增加这些可选项，不丢弃既有姓名/机构设置：

```json
{
  "preset": "reasoningbank-minimal-light",
  "color_policy": "auto-match",
  "favorite_color": "#1C4FA0",
  "body_font_pt": 26,
  "palette": {
    "primary": "所选主色",
    "heading": "在白底上可读的标题色",
    "body": "深色正文",
    "tint": "同色系浅底",
    "background": "#FFFFFF"
  }
}
```

这是字段示例；保存时把角色说明替换为实际颜色值。`keep-preset`、`institution-brand`、`provided-template`等既有选择仍然有效。用户说“以后用这套配色”才更新默认；只说“这次用”保留为当前报告覆盖。

### 应用清单

1. 解析个人默认和本次覆盖，记录本次有效署名、模式、机构、素材与配色。
2. 在新稿中应用，原始参照文件不改。日期来自当前报告信息，不从旧封面复制。
3. 更新封面、页头、章节导航、讲者身份页及文档作者元数据。正文无需反复印姓名或机构。
4. 部分继承页是整页图片，旧UNC标识已烘焙其中：重建干净的页面结构或仅提取证据区域，再叠加本次品牌；只替换可编辑封面不能算全稿完成。
5. 检查新稿与备注中的**讲者身份**是否一致。原论文作者/来源机构和原始图内引用属于研究证据，不能因个人换学校而篡改。
6. 交付时一句话说明采用的姓名、机构与是否只覆盖本次。已设置后不每次重开问卷。
