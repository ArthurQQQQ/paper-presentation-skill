# 从材料到报告

这个 skill 迁移的是理解与表达的判断。最终稿的白蓝外观只是其中一部分。

## 先找报告必须让听众理解的关系

先读原始材料、图表、方法和限制，列出支撑主线的证据。区分四种内容：来源实际报告的事实、用于帮助理解的改写或示意、讲者对机制的解释、尚待检验的研究假设。页面不混淆这些身份。

为报告写一句贯穿的问题，再给每页写一句回答。若同一页需要两个互不依赖的回答，拆页。若一页只有抽象名词，补上能说明该关系的对象、状态、具体例子或证据。

最终稿不是按论文段落等比例压缩：它先让听众理解 agent 的执行与经验对象，进入 ReasoningBank 的闭环，再解释实验测到了什么，最后把具体限制接到更广的记忆研究。

## 如何选择视觉形式

| 听众需要理解什么 | 适合的表达 | 保留什么 |
|---|---|---|
| 一个概念指的是什么 | 一个具体任务或对象，配一句定义 | 可观察行为和边界 |
| 系统有哪些部分、如何连接 | 总览图；随后局部放大 | 输入、输出、共享/持久状态、连接方向 |
| 一步操作怎样发生 | 机制在上，贯穿案例在下 | 操作前后发生变化的对象 |
| 两种方法差在哪 | 共同维度的对照表或并列路径 | 相同问题、相同比较条件 |
| 一项结果支持什么 | 大幅论文原图，配短结论 | 轴、图例、单位、比较组和有效范围 |
| 为什么一个解释不够 | 一对具体反例或缺失证据 | 两例只改变的关键条件 |
| 下一步研究做什么 | 论文的研究地图或大字可检验问题 | 哪个证据缺口、怎样区分解释 |
| 听众需亲自发现一个缺口 | 问题 → 停顿 → 新证据或更新 | 每次揭示带来的一个推理变化 |

根据关系在论文原图、原表和大字页之间选择。案例的关键对象与变化可用必要的可编辑短句配原图，细节口头展开；缺少原图不意味着把整个案例藏入备注。短句忠实转述来源，假设路径明确身份，不重绘论文图或编造实录数据。

## 总览、机制与贯穿案例

最终稿第 9 页先展示全系统。第 10–15 页保持右上角的小闭环图不动，只移动蓝色焦点。听众不用重新寻找当前讲到哪里。

详细讲解分清以下三件事：

- **机制是什么：** 例如任务 query 编码 → cosine similarity 排序 → 取一个 experience 的关联 atoms。
- **实例怎样走过机制：** 用首购问题展示新 query、历史经验和注入 prompt 的具体内容。
- **这是什么证据：** 这个排序与 atom 是讲解示意，不能称为论文测得的真实检索输出。

同一首购任务贯穿 trace、Judge、写入、分库和检索，减少换场景的负担。若原始证据迫使例子变化，像 extraction 页那样明确指出，不把两个任务混成一次执行。

案例的作用是使机制具体可读。不能用案例替代普遍机制，也不能把一个成功案例当成总体实验结论。

对另一篇方法论文，可以沿用这个结构：整体系统 → 保持位置的小总览 → 当前操作的输入/输出 → 同一任务的新状态。小总览必须换成新方法的真实结构，不能保留 ReasoningBank 的模块充数。

## 结果页的阅读顺序

一个有力的结果页通常让听众按顺序看到：**短标题指出发现 → 大图提供证据 → 少量准确数字帮助读取 → 必要限定说明含义**。

例如源稿讲失败经验时，结论来自 success-only 与 success+failure 的对照。它没有检验 failure-only 或失败比例。可以从这里提出污染问题，不能把污染写成已观察结果。

几个常见区分值得迁移：百分比与百分点；任务平均组别与逐题因果变化；步数与总 token 成本；实际选中答案与候选覆盖；检索条数与库容量；当前成功与未来迁移。只保留新材料实际涉及的区分。

一张图回答一个实验问题。原表太密时放大相关行列，保留会改变结论的条件。完整表可留作按需查阅的备份。

## 从边界进入研究

先讲清系统怎么做、结果怎么测，再提出“哪一项仍然不知道”。好的研究讨论可连成：

`观察到的结果 → 尚未区分的解释/未覆盖条件 → 可检验的问题 → 能区分它们的对照或设计`

讲解论文原图中的箭头时，说清是数据进入、状态更新、依赖还是评估反馈。讲者自己的研究问题用大字和备注呈现，标明哪些关系仍待检验。

## 讲者备注承担的内容

每页备注先写一句要说出的核心发现，再保留必要解释、关键限定、图表来源定位、示意身份和通往下一页的过渡。原文引用应定位到具体图、表、章节或实现版本。页面上的关键限制不能只藏在备注里。

备注用于支持讲述，避免把制作流程、验证日志和内部版式理由混入正式讲稿。

## 容易失去原稿优点的改写

- 只换成白底蓝字：补上页面问题、证据与视觉关系。
- 把每页做成几个同样大小的卡片：按对象之间的真实关系重新布局。
- 每页都换例子：优先让一个具体任务跨步骤演化。
- 照抄全文再缩小字号：选择支持主旨的证据，拆分独立问题。
- 每个标题都写口号或问句：结果用有依据的发现，机制写实际行为，定义直接命名。
- 用自制流程或重绘数据图替换论文原图：回到论文原图和原模板的图位。
- 只凭截图“长得像”就宣称完成：用新材料执行一次完整内容与视觉检查。
