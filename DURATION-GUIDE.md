# Same paper. Different depth.

Tell the skill your speaking time. It explains the level, structure and what to leave out before making slides.

| Speaking time | What the audience gets | What changes |
|---|---|---|
| 5 min | The contribution in focus | One problem, one idea, a minimal mechanism, decisive evidence and its limit. |
| 10 min | A focused overview | Minimal baseline, the core path through one example, main result. |
| 20 min | Understanding + assessment | Necessary background, stepwise mechanism, main evidence and one relevant diagnostic. |
| 30–40 min | A technical explanation | Assumptions, design choices and complementary evidence where reported. |
| 45–60+ min | A deep seminar | Detailed mechanism/theory, sourced alternatives, evidence boundaries and planned discussion. |

These are adaptable starting points, not fixed slide counts. Audience expertise and the source determine the final balance.

## Start here

```text
Use $artifact-template-reasoningbank-research-slides
Make a 20-minute academic talk from this paper, plus 5 minutes Q&A.
```

If no duration is supplied, it asks: **“How many minutes should the talk be? You can specify speaking time + Q&A.”** Paper reading continues while you answer. After the structure is set, any missing presenter name and school are confirmed before the cover; body slides and notes continue meanwhile.

## A 20-minute example

| Minutes | Purpose |
|---|---|
| 0–2 | Problem |
| 2–4 | Essential background + baseline |
| 4–5 | Key idea |
| 5–11 | Mechanism through one example |
| 11–17 | Main evidence + a relevant diagnostic |
| 17–20 | Conclusion + limits |

The skill adapts this estimate to the actual paper and audience. A 30-minute slot including 5 minutes Q&A leaves 25 minutes for the talk. A 15–20-minute request gets a complete 15-minute core plus optional expansion.

## What stays at every length

**Problem → changed mechanism → supporting evidence → scope.**

Shorter talks remove secondary material, not decisive conditions. Longer talks add understanding, not smaller text or invented results. Changing duration rebuilds the outline, depth, original-figure selection, notes and discussion budget together. Original template layouts and source figures remain the production basis.

Timing is estimated until rehearsed. Duration alone does not turn a paper talk into a field survey.
